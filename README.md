## Running the Code

To run either training or inference, first check the `run.sh` file
in the corresponding directory. Each script contains the launch command,
the configuration-file path, and the settings required to run the corresponding workflow.

## Acknowledgment

The training and inference code is based on [ResShift](https://github.com/zsyOAOA/ResShift).
We thank the authors for making their implementation publicly available.
